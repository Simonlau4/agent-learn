# 最小知识库起始模板（三分区 + AGENTS.md）

当用户明确要求从零搭建本地知识库时，按以下结构创建最小骨架；日常有现成仓库或 Vault 时直接复用已有结构，不重复创建。

```text
MyKnowledgeBase/
├── AGENTS.md          # 所有 Agent 的首读路由与回写纪律
├── Knowledge/         # 长期知识：项目资料、决策、结论、方法论
├── Memory/            # 可复用记忆：个人偏好、硬边界、工作流、索引
└── Workbench/         # 执行工作台：临时脚本、日志、测试输出（不直接升格为长期知识）
```

## 起始 `AGENTS.md` 模板

```markdown
# 本地知识库规则

## 分区与路由

| 目录 | 用途 | 写入内容 |
| --- | --- | --- |
| `Knowledge/` | 长期知识 | 项目现状、业务结论、决策、方法论 |
| `Memory/` | 可复用记忆 | 个人偏好与硬边界（`Memory/preferences.md`）、可复用工作流（`Memory/workflows/`） |
| `Workbench/` | 执行工作台 | 临时脚本、中间输出、运行日志、实验数据 |

## 读取与核验

1. 每次新对话先读本文件，再按任务关键词定位最相关的 1–3 个文件，不默认全库扫描。
2. 事实冲突优先级：当前真实系统或源码 > 当前项目文档 > `Memory/` 历史记忆。
3. 价格、政策、权限、接口参数、版本等易变事实，使用前先回真实环境核验。

## 回写纪律

1. 任务结束或用户点名记住某条经验时，按上表写回唯一正本并读回；新结论替代旧条目时直接覆盖旧文并标绝对日期。
2. 不写入完整聊天流水、报错日志、临时缓存以及密钥、token、密码等凭据。
3. 修改在用 Skill、删除或移动文件、对外发送以及 Git 操作，各自先征得用户当次同意。
```
